# Конвертер конфигураций в XML (Вариант 6)

Программа преобразует текст на учебном конфигурационном языке в XML.

## 📋 Особенности языка (Вариант 6)

- Числа: `123`, `45.67`
- Строки: `[[Текст]]`
- Массивы: `#( значение значение значение )`
- Словари: `{ имя = значение, ... }`
- Константы: `var имя значение;`
- Вычисления: `§имя 1 +§` (постфиксная форма)
